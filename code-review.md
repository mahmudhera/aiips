# Scientific review

1. **Containment ANI: formula confirmed, with model qualifications.**

   [Hera, Pierce-Ward & Koslicki (2023)](https://genome.cshlp.org/content/33/7/1061), Theorem 5, Equation (5), gives E[C_frac] = (1 - p)^k. Immediately after Theorem 6, the paper states the point estimator p_hat = 1 - C_frac^(1/k). Consequently ANI_hat = 1 - p_hat = C_frac^(1/k), matching `containment_ani` in `src/sketch/minhash.rs:351–358`.

   The paper assumes independent nucleotide substitutions and excludes spurious k-mer matches and repeats in its simple model. Its debiased FracMinHash containment estimator and confidence intervals are different from this code's containment estimate derived from classic MinHash Jaccard and estimated cardinalities. The transform matches; the paper's estimator guarantees do not automatically transfer. Taking a nonlinear root also does not preserve unbiasedness. Returning zero for an observed zero containment is an implementation convention, not evidence of zero biological identity.

2. **Hash family: heuristic approximation confirmed; one documentation correction remains.**

   The code uses h_i(x) = fmix64(x XOR seed_i), with seeds generated by SplitMix64 from one 64-bit user seed. The bijective finalizer prevents collisions between distinct encoded k-mers within a hash function, but bijectivity does not establish min-wise independence. All hash functions derive deterministically from the same seed, so they are not independently sampled random functions. No formal approximation-error bound is established for this family. These are conclusions from inspecting `src/hash.rs` and `MinHasher`, rather than a theorem about fmix64 supplied by a cited paper.

   [Broder et al., Min-Wise Independent Permutations](https://www.eecs.harvard.edu/~michaelm/NEWWORK/postscripts/minwise-conf.pdf), Equations (4)–(6), distinguish exact min-wise independence from approximation and connect the property to Jaccard estimation. The implementation already acknowledges its heuristic nature at the top of `src/sketch/minhash.rs` and in README's MinHash section.

   **[P2] Qualify the unconditional cardinality-unbiasedness claim** — `src/sketch/minhash.rs:317–319` and `README.md:171–172`. The exponential-minimum argument assumes independent uniform hash values in an ideal continuous model. The implemented finite, seeded permutation family does not establish those assumptions. State that the estimator is unbiased under that ideal model and is a practical approximation here. Similarly, describe the reported sampling-error formulas as ideal-model approximations that omit possible hash-family bias or dependence. This matters when interpreting scientific accuracy guarantees; repository guidance explicitly requires identifying statistical assumptions ([AGENTS.md:20–21](AGENTS.md#scientific-correctness)). No hash-algorithm replacement is justified by this review alone.

Validation: all 25 library tests and both MinHash integration tests passed. These include formula checks, known-set comparisons, and fixed-seed phiX174 mutation experiments. They demonstrate the tested cases, not universal hash-family independence or an approximation bound. Only this review document was written; source code and experimental results were unchanged.
